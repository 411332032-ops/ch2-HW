# 臺北市人口結構與十五歲以上人口婚姻狀況趨勢

用內政部「全國人口資料庫統計地圖」與「十五歲以上人口婚姻狀況」統計，做成可互動篩選的 BI 網頁，觀察臺北市 12 行政區人口高齡化結構與全國歷年婚姻狀況的長期變化。  
網頁：https://411332032-ops.github.io/ch2-HW/  
主題：臺北市十五歲以上人口結構（15-64歲與65歲以上）與全國十五歲以上人口婚姻狀況（未婚、有偶、離婚、喪偶）之長期趨勢  
資料來源：內政部（戶政司），《全國人口資料庫統計地圖》縣市表與《十五歲以上人口按性別、婚姻狀況及婚姻類型分(63)》  
資料期間：民國 63 年底至 114 年底（西元 1974–2025 年，每年一筆）

## 資料欄位

### 原始檔（`.csv` 與 `.xls`）

- `全國人口資料庫統計地圖.csv`：列為臺北市 12 行政區及「總計」列；欄為區域別、15-64歲總計、65歲以上總計。數字含千分位逗號。
- `十五歲以上人口婚姻狀況(63).xls`：工作表含民國 63 至 114 年全國數據；欄包含總計、未婚、有偶、離婚/終止結婚、喪偶。數字含千分位逗號，表頭為多層合併。

### 輸出（`output/cleaned_taipei_districts.csv`）

| 欄位 | 說明 |
|---|---|
| 區域別 | 臺北市 12 行政區名稱 |
| 15-64歲總計 | 青壯年與中齡人口數 |
| 65歲以上總計 | 高齡人口數 |
| 15歲以上總人口 | 該區十五歲以上總人口（15-64歲 + 65歲以上） |
| 高齡人口比例(%) | 65歲以上人口 ÷ 15歲以上總人口 × 100 |

### 輸出（`output/cleaned_marital_trends.csv`）

| 欄位 | 說明 |
|---|---|
| ROC_Year | 民國年 |
| AD_Year | 西元年 |
| Total_Population | 全國十五歲以上總人口 |
| Unmarried | 未婚人數 |
| Married | 有偶人數 |
| Divorced | 離婚人數 |
| Widowed | 喪偶人數 |

## ETL 處理與驗證

**處理**（`etl/etl.py`）

- 去除數字中的千分位逗號（`,`）與前後空白，將字串強制轉型為整數型態。
- **行政區資料**：過濾「總計」列，獨立保留 12 行政區數據，並計算「15歲以上總人口」與「高齡人口比例(%)」。
- **歷年婚姻資料**：解析 Excel 跨列合併標頭與多層結構，提取性別為「計」的歷年全國婚姻統計數字。

**驗證**（`etl/validate.py`，結果見 `etl/validation_log.txt`）

- 臺北市 12 行政區之「15-64歲人口」與「65歲以上人口」加總，必須精確等於官方宣告之總計人數（15-64歲：1,609,966 人；65歲以上：576,507 人）。
- 歷年婚姻數據：每一年之「未婚 + 有偶 + 離婚 + 喪偶」人數相加，必須 100% 精確等於當年的「總人口數」。

**驗證結果**（目前全部通過）

- 12 行政區人口加總 100% 符合官方總計（15-64歲 1,609,966 人；65歲以上 576,507 人；15歲以上總計 2,186,473 人）。
- 歷年婚姻狀況明細加總（民國 63 年至 114 年）100% 等於總人口數，驗證全部 PASS。

## 指標定義

| 指標 | 定義 |
|---|---|
| 15歲以上總人口 | 15-64歲人口數 + 65歲以上人口數 |
| 高齡人口比例 (%) | 65歲以上人口 ÷ 15歲以上總人口 × 100 |
| 有偶率（未婚率 / 離婚率） | 有偶（未婚 / 離婚）人數 ÷ 15歲以上總人口 × 100 |

## 限制

- 資料是依戶籍登記的教育程度與婚姻狀況編製，戶籍所在地不等於實際居住地。
- 行政區人口圖表呈現臺北市 12 行政區之年齡層結構；歷年婚姻狀況則採全國統計數據作為整體趨勢之代理分析。
- 圖表僅描述人口與婚姻結構變化之趨勢，不代表因果關係。

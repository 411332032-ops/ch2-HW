# 臺北市人口結構與 15 歲以上人口婚姻狀況統計儀表板

本專案針對臺北市 12 行政區人口結構及全國 15 歲以上人口婚姻狀況進行 ETL 資料清理與視覺化呈現。

👉 **線上展示網站**：[https://411332032-ops.github.io/ch2-HW/](https://411332032-ops.github.io/ch2-HW/)

---

## 📂 專案結構
- `Data/`: 原始 CSV、Excel 資料與圖片資產
- `docs/`: 網站發布目錄 (`index.html`, `data.js`)
- `etl/`: ETL 清理、自動驗證與數據打包程式
- `output/`: 清理後匯出之數據檔

---

## 📊 資料說明與限制
* **資料來源**：內政部戶政司《全國人口資料庫統計地圖》與《15歲以上人口婚姻狀況按性別及婚姻類型分》
* **資料期間**：民國 63 年至 114 年 (1974~2025年)
* **限制說明**：分區圖表呈現臺北市 12 行政區人口結構；歷年婚姻狀況採全國統計趨勢代理。

---

## 🛠️ ETL 自動化與驗證
* **加總核對 (Checksum Validation)**：12 行政區人口總計與歷年婚姻明細（未婚 + 有偶 + 離婚 + 喪偶 = 總數）均自動驗證通過，結果記錄於 `etl/validation_log.txt`。
